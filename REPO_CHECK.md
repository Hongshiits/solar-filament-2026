## 4. Reproduction steps

1. git clone the repository (weights come with the clone) and run python scripts/check_weights.py
2. place the official Kaggle download under data/MAGFiLO_1.0_Kaggle_2026/ (see docs/INFERENCE.md)
3. pip install -r requirements.txt (see README section 4)
4. execute notebooks/final_pipeline.ipynb (writes submission.csv); FILAMENT_DATA_ROOT overrides the data path
5. validate with python -m src.validate_submission submission.csv (or the notebook validation cell)
