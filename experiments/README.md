# Experiments (post-baseline iterations)

This directory archives the code and analysis notes for the iterations attempted after the
initial public-LB 0.39 baseline (reproduction of a public 10x U-Net ensemble). Everything here
is reproducibility material; the final submission is documented in the top-level README.

## What was tried, and what the evidence said

| Idea | Key numbers (honest fold0 OOF unless noted) | Verdict |
|---|---|---|
| Consensus soft-label semantic U-Net (smp U-Net + tu-tf_efficientnetv2_s, 1024/1280 crops, 5 folds) | single folds 0.407-0.443; 5-fold average proxy 0.4446 (leaky) / ~0.4365 debiased | weaker than the 0.4755 baseline |
| clDice loss A/B | fold0 bcedice 0.4211 vs clDice 0.4115 | negative (-0.0096), dropped |
| Probability-level fusion (baseline x semantic) | even optimistic proxy fusion 0.4751 < 0.4755 | does not clear the +0.003 gate |
| Mask-level fusion / recover / consensus | 0.4508-0.4584 | negative |
| Multi-scale TTA (0.85/1.0/1.15) | -0.056 .. -0.35 PQ | clearly negative |
| Instance rescorer / stacking (HGB, 22 features) | AUC 0.71 but best PQ +0.0009 | no gain (FP->FN trade-off) |
| KEEP post-processing re-tuning | best = original rule | no change |
| Public 25-model YOLO/MaskRCNN/ConvNeXt ensemble reproduction (15 YOLO checkpoints, 8-view TTA, consensus) | own pipeline LB 0.39 (1259-instance vote-filtered variant) | ties baseline; the public 0.41 needs the remaining families + refiner/rescorer |
| Cross-model support pruning / union of two 0.39 solutions | sparse-label simulation: union -0.02, pruning ~neutral | submitted variants; the safest is the baseline |

## Compliance

- No leaked test annotations, no external labeled data, inference only on official test images.
- Public model weights are used and credited (baseline 10x U-Net; 15-model YOLO set). A publicly
  posted submission file was found but is **not** used: submissions must be produced by our own code.
- All submission candidates here are generated by the scripts in this directory.

## Layout

- `code/` - training / inference / fusion / candidate-generation scripts.
- `notes/` - experiment logs, fusion commands, negative-result archive.
## Post-processing and rescorer experiments (negative, 2026-11-06)

All three were evaluated on the honest fold-0 out-of-fold predictions of the reproduced public ensemble
(baseline pooled PQ 0.4755: TP/FP/FN = 1238/528/579) and none improves the score:

| experiment | result | verdict |
|---|---|---|
| learned instance rescorer (GBM, 21 geometry + probability features, grouped 5-fold CV) | OOF AUC 0.6797; dense PQ 0.4753/0.4747/0.4733/0.4740/0.4748/0.4718/0.4672 at tau=0.05..0.50; sparse-sim (r=0.77) 0.4104-0.4118 vs 0.4140 baseline | negative: the hand-tuned KEEP rule (mean prob >= 0.85) is already optimal |
| watershed splitting of predictions that merge >= 2 GT instances | 52 splits; PQ 0.5365 -> 0.3820 on a 40-image subset (-0.1545) | strongly negative: split parts fall below IoU 0.5 |
| adding low-confidence detections outside existing masks | 50-56 instances added; PQ -0.0016/-0.0024/-0.0042 | negative: mostly false positives |

Conclusion: post-processing cannot raise the score beyond the published KEEP rule; the remaining gap is model quality.
